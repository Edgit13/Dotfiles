# Nook brand assets

Source files for the Nook identity. Everything is available as PNG (raster)
and SVG (vector).

| Folder | Use |
|---|---|
| `avatar/` | GitHub / social profile picture |
| `extra/` | Logo mark and `nook` wordmark |
| `nook-rice/` | Banner and icon for the **Edots** dotfiles repo |
| `nook-wallpapers/` | Banner and icon for the **Rice-Wallpapers** repo |

Palette: black `#000000`, off-white `#F4F1EA`, lavender `#CDBFF0`,
purple `#6B4EBA`, red `#E01B24`.

Repo copies used by the README:

- `screenshots/banner.png` ← `nook-rice/nook-rice-banner.png`
- `screenshots/icon.png` ← `nook-rice/nook-rice-icon.png`
- `../screenshots/...` in the wallpapers repo ← `nook-wallpapers/`
