Media, brightness and playback keys work while the screen is locked. Surfaces opened from a keybind appear on the focused monitor; clicking a bar module opens it on that bar's monitor.

CLI and IPC

The edots command wraps every surface and action:

edots launcher           # also: wall, clipboard, wifi, mixer, audio, media, power, binds
edots settings
edots dashboard
edots tasks
edots screenshot         # "stop" ends a recording
edots ocr                # select a region and copy its text
edots lens               # select a region and search with Google Lens
edots notifications      # open|toggle|close|clear|read|clear-read|dnd
edots notifications mute ghostty
edots app-audio          # ui|sinks|route|forget|apply
edots plugin             # open|enable|disable|toggle|reload|folder|path
edots nightlight         # on|off|toggle|temp N|status
edots updates            # open|refresh|update
edots theme toggleDesign # Material <-> Nothing
edots faceid             # status|setup|enroll|test|remove
edots reload
edots doctor

For raw Quickshell IPC:

edots ipc pill toggleLauncher
qs -p ~/.config/quickshell/bar/shell.qml ipc call dashboard toggle
