Install

Get it running

Edots targets Arch-based distributions with MangoWM and Quickshell. The installer also has a generic path for Debian, Fedora, openSUSE and Gentoo, and a NixOS bootstrap — anything missing from those repos is listed instead of aborting.

Requirements

  • Quickshell with Io, Wayland, Services, Networking, UPower, Pipewire and Mpris.
  • MangoWM (mangowc-git) — the shell talks to its JSON mmsg IPC.
  • Fonts: JetBrainsMono Nerd Font, Material Symbols Rounded, Google Sans Flex. SF Pro Display and SF Mono are optional and proprietary.
  • Tools: matugen, awww, cliphist, brightnessctl, nmcli, rfkill, playerctl, grim, tesseract, python3, python-pillow, jq.
  • Lock screen: gcc and PAM headers — install.sh builds pam-auth.
  • Face ID: a webcam. Setup keeps OpenCV in a private venv and downloads two ONNX models (~38 MB); the system Python is untouched.

Install

git clone https://github.com/Edgit13/Dotfiles ~/Dotfiles
cd ~/Dotfiles
./install.sh

Or straight from the repository:

curl -fsSL https://raw.githubusercontent.com/Edgit13/Dotfiles/master/install.sh | bash

Flags

FlagWhat it does
--autoNo questions. Aliases: --quickstart, --yes.
--minimalSkip optional apps (vlc, nautilus, dolphin, firefox, flatpak, …).
--no-depsSkip packages and only deploy configs plus the finishing steps.
--dry-runPrint the plan and change nothing. Not available for the NixOS path.
--restoreRemove the symlinks and restore the latest ~/.config-backup-*.
--disk=, --user=, --password=NixOS auto-installer only.

What the installer does

  1. Clones the repo and Rice-Wallpapers into ~/Pictures/Wallpapers.
  2. Installs packages from pacman and the AUR, bootstrapping yay when needed.
  3. Installs Google Sans Flex.
  4. Runs ./sync.sh install — symlinks configs into ~/.config and installs the edots command.
  5. Registers and starts the swayidle user service.
  6. Builds lockscreen/pam-auth.
  7. Generates the first palette from the first wallpaper.
  8. Builds the wallpaper colour index (needs python-pillow).
  9. Links the Firefox chrome files into the profile Firefox actually launches.
After installing: log out and back in so fish, swayidle and systemd pick up the environment, then run passwd if this is a fresh account — the lock screen needs a real password.

Start and check

edots reload          # restart the bar
edots doctor          # packages, fonts, symlinks, services, palette
edots settings        # open Settings (Super+A)

edots doctor verifies packages, fonts, config symlinks, the running bar, systemd services, the palette and the Firefox chrome. It also has a JSON mode for scripts.

Wallpaper colours need an index. The installer runs it once; later use Settings → Wallpapers → Analyze wallpapers. It writes ~/.cache/quickshell/wallpaper-colors.json and never touches your images.

Update

cd ~/Dotfiles
git pull
./install.sh --no-deps      # re-deploy symlinks and finishing steps
edots reload

The update centre in the bar checks pacman, AUR and Flatpak and never installs anything on its own. Use edots updates to open it.

NixOS

The nix/ folder has modules for NixOS plus home-manager, including the MangoWM flake, Quickshell and the capture stack. See nix/README.md. install.sh validates the flake and prints the integration steps.
