Themes

One palette,
two languages

The palette comes from your wallpaper. The design decides how it is allowed to look: Material 3 tonal surfaces, or Nothing monochrome with a single red accent. Everything else — widgets, keybinds, layout — stays identical.

Material 3 Expressive vs Nothing

Material 3 Expressive
Nothing
Tonal colour roles, large rounded shapes, soft elevation shadows.
Black and off-white, hairline borders, no gradients, one red accent.
Rounded pills and filled buttons; state is shown with colour.
Dot-matrix numerals and labels; state is shown with weight and dots.
Material Symbols Rounded, Google Sans Flex.
SF Mono / JetBrains Mono, dot-matrix display faces.
Corner style, elevation, shadows and UI scale are shared settings.
Same settings — the Nothing design just interprets them strictly.
The lock screen follows the design too: LockM3.qml and LockNothing.qml share the same state and settings.

Switch and tune

edots theme                  # design, mode, accent and applied palette
edots theme toggleDesign     # Material <-> Nothing
edots theme setMode dark     # dark | light | toggleMode
edots theme setTransition dots   # off | fade | dots | scan
edots theme sync             # repaint GTK, terminals, Firefox, rofi and KDE

All of it is also in Settings → Theme: design, light/dark mode, transition, corner style, shadows, UI scale and animation speed. The transition plays whenever the design or the mode changes.

Wallpaper palette

wallcolors.py extracts a palette from the current wallpaper and writes it to the files each application reads. Changing the wallpaper can recolour the whole session in one pass:

TargetFile
Shellquickshell/colors.json
GTK 3 / GTK 4gtk-3.0/gtk-colors.css, gtk-4.0/gtk-colors.css
kitty / ghosttykitty-colors.conf, ghostty-colors.conf
Firefox chromefirefox-colors.css in the active profile
rofirofi/colors.rasi
KDE / Qt appskdeglobals

The wallpaper selector can filter by the dominant colour. That index is built once by the installer and can be rebuilt in Settings → Wallpapers → Analyze wallpapers; it lives in ~/.cache/quickshell/wallpaper-colors.json and never modifies images.

Night light

Warm the screen with gammastep — manual temperature or a daily schedule. It is a one-shot helper, not a daemon: it applies the config and exits.

edots nightlight on
edots nightlight temp 4000
edots nightlight status
edots nightlight off

Settings live in quickshell/nightlight.json: enabled, mode (manual or schedule), temperature, day and night temperature, sunset and sunrise.

Lock screen designs

The lock screen has its own settings page under System → Lock screen: layout, clock style and weight, widgets, wallpaper fill and effects, password style, power buttons, Face ID and an advanced developer mode.

Developer mode only whitelists safe hotkeys while locked — screenshot, media, volume and brightness. They never unlock the session.
